## Run locally

Prerequisites: Node.js and npm.

```bash
git clone https://github.com/manikumarkundena/manikumarkundena_portfolio.git
cd manikumarkundena_portfolio
npm install
npm run dev
```

Available scripts:

- `npm run dev` — start the Vite development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build
- `npm run lint` — run the TypeScript check configured by the project

## Environment configuration

Review the repository's environment usage before running. Never commit API keys, credentials, or local environment files. Keep actual secrets in a local `.env.local` or the deployment provider's environment settings.
